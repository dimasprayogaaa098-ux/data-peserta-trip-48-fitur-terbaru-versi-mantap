PAKET WEB DATA PESERTA TRIP 48

1. Upload index.html ke repository GitHub Pages.
2. Buka website melalui HTTPS.
3. Fitur daftar peserta, detail, dan QR pribadi sudah tersedia.
4. Untuk menyimpan absensi online sungguhan, buat project Firebase:
   - aktifkan Anonymous Authentication
   - buat Firestore Database
   - hubungkan kode scan dengan Firebase Firestore
   - gunakan firestore.rules sebagai dasar aturan keamanan

PENTING: Data berisi nomor HP. Pastikan peserta menyetujui publikasi data.
